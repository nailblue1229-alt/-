# 사이의 거리 — 읽기 앱

단편 소설 「사이의 거리」(전 8장, 31,931자)를 휴대폰에서 읽기 위한 설치형 웹앱(PWA)입니다.
원본 한글 문서(`.hwp`)에서 본문을 추출하고, 강제 개행으로 끊겨 있던 줄을 919개 문단으로 다시 이어 붙였습니다.

## 용량

전체 **약 125KB**. 웹폰트를 쓰지 않고 휴대폰에 이미 있는 시스템 글꼴을 사용하므로
설치 후 차지하는 공간이 사실상 없고, 처음 열 때 로딩도 즉시 끝납니다.

| 파일 | 크기 | 역할 |
| --- | --- | --- |
| `index.html` | ~113KB | 본문 + 읽기 화면 (단일 파일) |
| `sw.js` | ~1KB | 오프라인 캐시 (서비스 워커) |
| `manifest.webmanifest` | ~1KB | 앱 이름·아이콘·전체화면 설정 |
| `icon-*.png` | ~8KB | 홈 화면 아이콘 |

## 기능

- 글자 크기 14~24px, 줄 간격 3단계, 서체 명조/고딕
- 화면 자동 / 밝게 / 어둡게
- 차례에서 장 이동, 상단 진행률 표시
- 읽던 위치 기억 → 다시 열면 **이어읽기**
- 한 번 열어두면 **오프라인에서도** 그대로 읽힘 (지하철·비행기)
- 설정은 기기에 저장되어 다음에 열어도 유지

## 폰에 설치하기

1. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`,
   Branch를 `claude/mobile-readability-9vq42k` / `/ (root)`로 지정하고 Save.
2. 1~2분 뒤 `https://nailblue1229-alt.github.io/-/` 주소가 열립니다.
3. 휴대폰에서 그 주소를 열고
   - **아이폰(Safari)**: 공유 버튼 → `홈 화면에 추가`
   - **안드로이드(Chrome)**: 메뉴 → `앱 설치` (또는 읽기 설정 안의 `홈 화면에 추가` 버튼)

설치하면 주소창 없는 전체화면으로 열리고, 홈 화면에 아이콘이 생깁니다.

## 다시 만들기

`index.html`은 원본 `.hwp`에서 생성한 파일입니다. 본문을 고칠 일이 있으면
`index.html`을 직접 수정하면 됩니다 — 빌드 도구나 의존성은 필요 없습니다.
