# 유튜브 쇼츠 인기영상 찾기

`shorts-finder.html`을 브라우저로 열고, YouTube API 키와 검색어를 넣으면 최근 인기 쇼츠를 찾아줍니다.

- 기간(24시간~1년), 국가, 언어, 최소 조회수 필터
- 3분 이하 영상만 표시 (쇼츠)
- 하루당 조회수(급상승) / 총 조회수 / 좋아요 / 댓글 / 최신순 정렬
- CSV 저장 (엑셀에서 열림)

## API 키 발급 (무료)
1. https://console.cloud.google.com 접속 → 프로젝트 만들기
2. "API 및 서비스 → 라이브러리"에서 **YouTube Data API v3** 사용 설정
3. "사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키"
4. 만든 키를 페이지에 붙여넣기

무료 할당량은 하루 10,000 단위이고, 검색 한 번(50개)에 약 100 단위를 씁니다.
