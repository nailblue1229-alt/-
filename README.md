# TTS Emotion Studio

대본을 입력하면 본인의 ElevenLabs 계정 보이스로 감정이 실린 TTS 음성을 생성하는 웹앱입니다.

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

## 사용 방법

1. 우측 상단 **API 키 설정** 버튼을 눌러 본인의 ElevenLabs API 키를 입력합니다. (키는 브라우저에만 저장되고, 음성 생성 요청 시에만 서버를 거쳐 ElevenLabs로 전달됩니다.)
2. 보이스 드롭다운에서 본인 계정에 등록된 보이스를 선택합니다.
3. 대본을 입력합니다.
4. **감정조절** 또는 **감정태그 모범사례** 버튼으로 `[happy]`, `[sad]`, `[whispers]` 같은 감정 태그를 커서 위치에 삽입할 수 있습니다. (감정 태그는 `eleven_v3` 계열 모델에서 지원됩니다.)
5. stability(감정 풍부 / 자연 / 안정)를 선택합니다.
6. **TTS 생성하기**를 누르면 음성이 생성되고, 바로 재생하거나 다운로드할 수 있습니다.

## 참고

- 개인 로컬 사용을 전제로 한 MVP입니다. API 키가 브라우저 로컬 스토리지에 평문 저장되므로, 신뢰할 수 있는 환경에서만 사용하세요.
- 자막(SRT) 생성, 대본 히스토리 등은 아직 포함되어 있지 않습니다. 다음 단계로 추가할 수 있습니다.
