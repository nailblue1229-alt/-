# 인스타 게시일 표시기 (Instagram Post Info)

인스타그램에서 **게시물이 언제 올라왔는지**, 그리고 **조회수 · 댓글 개수 · 좋아요 개수**를
썸네일 위에 바로 표시해 주는 크롬 확장 프로그램입니다.

프로필 그리드, 탐색 탭, 릴스 목록, 저장한 게시물 등 썸네일이 보이는 곳이면 어디서든
일일이 클릭해 들어가지 않고 한눈에 확인할 수 있습니다.

기본으로 보여주는 것은 **날짜 · 조회수 · 댓글수** 세 가지입니다.
(좋아요는 꺼져 있고, 팝업에서 켤 수 있습니다.)

```
프로필 그리드처럼 썸네일이 작을 때      게시물 상세처럼 넓을 때
┌──────────────┐                     ┌────────────────────────┐
│              │                     │                        │
│   (썸네일)    │                     │       (게시물)          │
│              │                     │                        │
│  📅 08.28    │                     │  📅 2026.08.28 15:24 · 3일 전
│  ▶ 15.2만    │                     │  ▶ 152,340   💬 412     │
│  💬 412      │                     │                        │
└──────────────┘                     └────────────────────────┘
   날짜를 자동으로 줄여                  넓은 곳에서는 전체 표기
   세 줄이 다 들어가게 함
```

## 주요 기능

- **업로드 날짜/시각** — `2026.08.28 15:24`, `3개월 전`, 또는 둘 다 표시
- **조회수** — 동영상·릴스의 재생 수
- **댓글 개수**, **좋아요 개수** (선택)
- **게시물 상세 페이지** — 인스타가 보여주는 "3일 전" 옆에 정확한 날짜를 붙여줌
- 썸네일이 좁으면 날짜를 `08.28` 로 자동으로 줄여 세 줄이 모두 들어가게 함
- 배지 위치(네 모서리), 글자 크기, 숫자 표기(`1.2만` / `12,345`)를 팝업에서 조절
- 배지 기본 위치는 **오른쪽 아래**. 썸네일 왼쪽 아래를 쓰는 다른 확장 프로그램
  (IG Sorter 등)과 겹치지 않게 하기 위한 기본값이며, 팝업에서 바꿀 수 있습니다
- 한 번 본 게시물 정보는 캐시에 남아 다시 볼 때 즉시 표시 (14일 보관, 언제든 삭제 가능)

## 설치 방법

크롬 웹스토어에는 올리지 않았기 때문에, 파일을 내려받아 직접 넣는 방식입니다.
설치는 딱 4단계, 2분이면 끝납니다.

### 1단계 — 파일 내려받기

아래 주소를 눌러 zip 파일을 받습니다.

**https://github.com/nailblue1229-alt/-/archive/refs/heads/claude/instagram-post-date-extension-xe730i.zip**

(GitHub 페이지에서 받고 싶다면: 저장소 → 브랜치를
`claude/instagram-post-date-extension-xe730i` 로 바꾸고 → 초록색 **Code** 버튼 →
**Download ZIP**)

### 2단계 — 압축 풀기

받은 zip 을 압축 해제합니다. 폴더 안에 **`manifest.json` 파일이 보이는 위치**를
기억해 두세요. 그 폴더가 크롬에 등록할 폴더입니다.

> GitHub 에서 받은 zip 은 압축을 풀면 폴더가 한 겹 더 있을 수 있습니다
> (`--claude-instagram-post-date-extension-xe730i` 같은 이름).
> 그 안쪽, `manifest.json` 이 바로 보이는 폴더를 골라야 합니다.

### 3단계 — 크롬에 올리기

1. 크롬 주소창에 `chrome://extensions` 를 입력해 엽니다.
2. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
3. 왼쪽 위에 나타나는 **압축해제된 확장 프로그램을 로드합니다** 버튼을 누릅니다.
4. 2단계에서 확인한 폴더를 선택합니다.

### 4단계 — 확인

`https://www.instagram.com` 을 열고 새로고침(F5)하면 썸네일 위에 배지가 나타납니다.
툴바의 퍼즐 조각 아이콘에서 이 확장을 고정해 두면 설정 팝업을 바로 열 수 있습니다.

> 압축을 푼 폴더는 지우면 안 됩니다. 브라우저가 그 폴더를 계속 참조합니다.

### 엣지(Edge)에서 설치하기

엣지도 크로미움 기반이라 그대로 동작합니다. 버튼 위치와 이름만 다릅니다.

1. 주소창에 **`edge://extensions`** 를 입력합니다. (`chrome://` 아님)
2. **왼쪽 사이드바 아래쪽**의 **개발자 모드** 스위치를 켭니다.
   (크롬은 오른쪽 위, 엣지는 왼쪽 아래입니다.)
3. **압축을 푼 항목 로드** 버튼을 누릅니다.
   (크롬의 "압축해제된 확장 프로그램을 로드합니다" 와 같은 기능입니다.)
4. `manifest.json` 이 들어 있는 폴더를 선택합니다.

설치 후 "이 확장은 Microsoft Store 에서 오지 않았습니다" 같은 안내가 뜰 수 있는데,
직접 설치한 확장이라 그렇습니다. **유지** 를 누르면 됩니다.

웨일(Whale), 브레이브(Brave), 오페라(Opera) 등 다른 크로미움 계열 브라우저도
`설정 → 확장 프로그램 → 개발자 모드` 순서로 같은 방식입니다.

**필요 버전:** 크롬/엣지 **111 이상**. (2023년 3월 이후 버전이면 모두 해당됩니다.
`edge://settings/help` 에서 확인할 수 있습니다.)
사파리와 파이어폭스는 확장 구조가 달라 지원하지 않습니다.

### 잘 안 될 때

| 증상 | 확인할 것 |
| --- | --- |
| "매니페스트 파일이 없습니다" 오류 | 고른 폴더 안에 `manifest.json` 이 바로 있는지 (폴더가 한 겹 더 있는 경우가 많습니다) |
| 배지가 안 보임 | 인스타그램 탭을 새로고침했는지, 팝업의 **표시 켜기** 가 켜져 있는지 |
| 날짜만 나오고 조회수가 없음 | 아래 **조회수가 안 보일 때** 를 참고하세요 |
| 엣지에서 로드 버튼이 안 보임 | 왼쪽 사이드바 아래의 **개발자 모드** 를 먼저 켜야 버튼이 나타납니다 |

### 조회수가 안 보일 때

조회수는 기본으로 켜져 있습니다. 그래도 숫자가 없다면 대개 아래 중 하나입니다.

1. **사진 게시물이라서** — 인스타그램은 사진 게시물의 조회수를 공개하지 않습니다.
   조회수 지표가 있는 것은 **동영상과 릴스** 뿐입니다. 이 경우 배지에는 날짜와
   댓글수만 나오는 것이 정상입니다.
2. **아직 정보를 받기 전이라서** — 인스타그램이 해당 게시물 데이터를 아직
   내려주지 않은 상태입니다. 스크롤을 조금 내렸다 올리거나 새로고침하면 채워집니다.
   이때 동영상에는 흐린 `▶ –` 가 표시되어 "동영상인데 숫자를 못 받았다"는 것을
   구분할 수 있습니다. (팝업에서 끌 수 있습니다.)
3. **정말 동작하지 않아서** — 팝업 아래쪽의 `저장된 게시물 N개 · 조회수 있음 M개`
   를 확인하세요. N이 0이면 수집 자체가 안 되는 것이고, N은 늘어나는데 M이 0이면
   보고 계신 게시물이 전부 사진일 가능성이 높습니다.

## 사용법

- 툴바의 확장 프로그램 아이콘을 누르면 설정 팝업이 열립니다.
- 설정을 바꾸면 열려 있는 인스타그램 탭에 곧바로 반영됩니다. (반영이 안 되면 F5)
- 배지가 거슬릴 때는 팝업 맨 위의 **표시 켜기** 스위치만 끄면 됩니다.

## 어떻게 동작하나요

인스타그램 웹앱은 화면을 그리기 위해 자체 API(`/api/v1/…`, `/graphql/…`)를 호출하고,
그 응답 안에는 이미 업로드 시각(`taken_at`), 재생 수(`play_count`), 댓글 수(`comment_count`) 같은
값이 들어 있습니다. 다만 화면에는 대부분 표시하지 않을 뿐입니다.

이 확장 프로그램은 그 **응답을 읽어서 화면에 표시**만 합니다.

- `src/interceptor.js` — 페이지 월드에서 `fetch` / `XMLHttpRequest` 를 감싸 응답 JSON에서 게시물 정보를 추출
- `src/content.js` — 추출된 정보를 모아두고 썸네일 위에 배지를 그림
- `src/format.js` — 날짜·숫자 표시 형식(순수 함수, 테스트 대상)
- `src/popup.*` — 설정 화면
- `src/background.js` — 설치 시 기본 설정 채우기

정보를 아직 받지 못한 썸네일은, 설정에서 허용한 경우에 한해 로그인 없이도 열람 가능한
공개 embed 페이지(`/p/<코드>/embed/captioned/`)를 동시 2건·요청 간 350ms 간격으로 조회해 보충합니다.
실패한 코드는 30분 동안 재시도하지 않습니다.

## 개인정보 / 권한

- 권한은 `storage`(설정과 캐시 저장) 하나, 접근 범위는 `https://www.instagram.com/*` 뿐입니다.
- 수집한 정보는 **내 브라우저 안에만** 저장되며, 외부 서버로 아무것도 전송하지 않습니다.
- 계정 정보, 비밀번호, 쿠키를 읽거나 저장하지 않습니다.
- 로그인한 내가 이미 볼 수 있는 데이터만 다룹니다. 비공개 계정을 몰래 들여다보는 기능은 없습니다.

## 알려진 한계

- **조회수는 동영상과 릴스에만 있습니다.** 일반 사진 게시물은 인스타그램이 조회수를
  제공하지 않으므로 표시되지 않습니다. 확장 프로그램이 만들어낼 수 있는 값이 아닙니다.
  캐러셀(여러 장) 게시물은 안에 동영상이 있으면 그 조회수를 대신 보여줍니다.
- 인사이트에만 있는 **노출수(impressions)·도달수(reach)** 는 조회수와 다른 지표라
  일부러 쓰지 않습니다. 조회수 자리에 다른 숫자를 채워 넣지 않습니다.
- 인스타그램이 API 응답 구조를 바꾸면 일부 값이 비어 보일 수 있습니다.
  그럴 때는 `src/interceptor.js` 의 `viewsOf` / `commentsOf` / `takenAt` 에 필드 이름을 추가하면 됩니다.
- 남의 비공개 게시물처럼 원래 볼 수 없는 내용은 이 확장으로도 볼 수 없습니다.
