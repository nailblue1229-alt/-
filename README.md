# 샤오홍슈(小红书) 일괄 다운로더

공유 텍스트를 **그대로 한꺼번에 붙여넣으면** 영상(과 이미지)을 순서대로 내려받습니다.
파이썬 표준 라이브러리만 사용하므로 **따로 설치할 패키지가 없습니다.**

```
87 [饭盒优等生，분격 설계… - 一碗小面面| rednote …] jfHaah6nCCkXNqn https://www.xiaohongshu.com/discovery/item/69c2…?xsec_token=…
88 [다른 영상] http://xhslink.com/a/…
89 [또 다른 영상] https://www.xiaohongshu.com/explore/…
```
위처럼 번호·제목·토큰이 섞여 있어도 URL만 알아서 골라내고, 같은 노트가 여러 번 있으면 한 번만 받습니다.

## ⭐ 크롬 확장 프로그램으로 쓰기 (권장)

샤오홍슈는 로그인하지 않은 접속에 노트 내용을 주지 않고, 브라우저 쿠키를 다른
프로그램에 옮겨 쓰면 그 세션을 끊어버립니다. 그래서 **로그인된 크롬 안에서 직접
동작하는 확장 프로그램**이 가장 확실합니다. 쿠키를 복사할 필요가 없습니다.

### 설치

1. https://github.com/nailblue1229-alt/-/releases/tag/app-latest 에서
   **`XHS-Chrome-Extension.zip`** 을 내려받습니다
2. 우클릭 → **압축 풀기** (안에 `xhs-extension` 폴더가 나옵니다)
3. 크롬 주소창에 `chrome://extensions` 입력 → Enter
4. 오른쪽 위 **개발자 모드**를 켭니다
5. 왼쪽 위 **`압축해제된 확장 프로그램을 로드합니다`** 클릭
6. 압축을 푼 **`xhs-extension` 폴더**를 선택합니다

> 폴더는 지우거나 옮기면 안 됩니다. 크롬이 그 위치에서 확장을 읽습니다.

### 사용법 1 — 보면서 하나씩 (가장 확실)

노트를 크롬에서 열면 **오른쪽 아래에 빨간 `⬇ 영상 저장` 버튼**이 뜹니다. 누르면
바로 받아집니다. 이미지 노트면 `⬇ 이미지 N장 저장` 으로 바뀝니다.

버튼이 `준비 중…` 인 채로 있으면 영상이 아직 안 불러와진 것입니다. 잠깐 기다리거나
영상을 한 번 재생하면 활성화됩니다.

### 사용법 2 — 링크를 모아서 한꺼번에

1. 툴바의 확장 아이콘을 눌러 작업 페이지를 엽니다
2. 큰 입력칸에 공유 텍스트를 통째로 붙여넣습니다
3. **다운로드 시작**

노트를 하나씩 탭으로 열어 주소를 읽고 닫습니다. **탭이 열렸다 닫히는 동안 다른 작업을
하지 마세요.** 샤오홍슈는 화면에 보이는 탭에만 영상 데이터를 내려주기 때문에, 탭을
숨기거나 다른 창으로 가리면 실패합니다.

저장 위치는 두 방식 모두 크롬 다운로드 폴더 아래 `xiaohongshu` 폴더입니다.
`요청 간격`은 기본 3초이며, 낮추면 차단될 수 있습니다.

## 데스크톱 프로그램 (윈도우)

> ⚠️ **현재 대부분의 노트에서 실패합니다.** 샤오홍슈가 노트 데이터를 HTML에 넣지
> 않고 화면이 뜬 뒤 따로 불러오도록 바꾸면서, 페이지를 받아 읽는 이 방식으로는
> 영상 주소를 얻을 수 없게 됐습니다. 위의 **크롬 확장**을 쓰세요.
> 아래 내용은 참고용으로 남겨 둡니다.

1. 아래 주소로 들어갑니다
   → https://github.com/nailblue1229-alt/-/releases/tag/app-latest
2. **`XHS-Downloader-Windows.zip`** 을 내려받습니다
3. 우클릭 → **압축 풀기**
4. 풀린 `XHS-Downloader` 폴더 안의 **`XHS-Downloader.exe`** 를 더블클릭

폴더 안에는 exe 말고도 `_internal` 폴더가 함께 들어 있습니다. **폴더째로 두고 써야** 합니다
(exe만 다른 곳으로 옮기면 실행되지 않습니다). 폴더를 통째로 바탕화면에 두고,
exe를 우클릭 → **바로 가기 만들기** 로 단축 아이콘을 만들어 쓰면 편합니다.

### 백신이 악성코드라고 할 때

알약·V3·Windows Defender 등이 이 파일을 경고할 수 있습니다. **PyInstaller로 만든
서명 없는 프로그램에서 흔히 나오는 오탐**이지만, 남의 말만 믿지 말고 직접 확인하세요.

1. **어떤 코드로 만들어졌는지 확인** — 이 저장소의 소스 전부가 공개되어 있고,
   실행 파일은 제 컴퓨터가 아니라 **GitHub 서버가 그 소스로 직접 빌드**했습니다.
   릴리스 노트의 `빌드 로그` 링크에서 빌드 과정 전체를 볼 수 있습니다.
2. **파일이 바뀌지 않았는지 확인** — 릴리스 노트에 zip의 SHA256 해시가 적혀 있습니다.
   PowerShell에서 아래를 실행해 값이 같은지 비교하세요.
   ```powershell
   Get-FileHash .\XHS-Downloader-Windows.zip -Algorithm SHA256
   ```
3. **여러 백신으로 교차 확인** — https://www.virustotal.com 에 zip을 올려 보세요.
   70여 개 엔진 중 극소수만 경고한다면 오탐일 가능성이 높습니다.

확인 후에도 백신이 계속 막는다면, 그 폴더를 백신의 **예외(제외) 목록**에 추가해야 합니다.
찜찜하시면 **차라리 아래의 파이썬 실행 방식을 쓰세요.** 소스 코드를 그대로 돌리는 것이라
백신이 문제 삼지 않습니다.

### 직접 빌드하고 싶다면

```bash
pip install pyinstaller
python build_app.py     # dist/XHS-Downloader/ 폴더가 생깁니다
```

## 파이썬으로 실행하기 (개발자용)

### 준비

- 파이썬 3.9 이상 (윈도우/맥은 https://python.org 설치본에 GUI용 tkinter가 포함되어 있습니다)
- 리눅스에서 GUI를 쓰려면: `sudo apt install python3-tk`

### 실행 방법

### GUI (권장)

| 운영체제 | 방법 |
| --- | --- |
| 윈도우 | `run_gui.bat` 더블클릭 |
| 맥 | `run_gui.command` 더블클릭 (첫 실행 시 우클릭 → 열기) |
| 공통 | `python -m xhs_dl --gui` |

1. 큰 입력창에 공유 텍스트를 **Ctrl+V로 통째로 붙여넣기**
2. 저장 폴더 확인
3. **다운로드 시작** 클릭 — 아래 로그에 진행 상황이 한 줄씩 표시됩니다

### 명령줄

```bash
# 파일에 모아둔 링크 처리
python -m xhs_dl -i links.txt -o ~/Downloads/xhs

# 링크를 인자로 바로 전달
python -m xhs_dl "87 [제목] https://www.xiaohongshu.com/discovery/item/…"

# 파이프로 붙여넣기 (Ctrl+D 로 입력 종료)
python -m xhs_dl < links.txt

# 실제로 받지 않고 인식된 링크만 확인
python -m xhs_dl -i links.txt --list
```

주요 옵션

| 옵션 | 설명 |
| --- | --- |
| `-o, --out DIR` | 저장 폴더 |
| `--cookie` / `--cookie-file` | 로그인 쿠키 (아래 참고) |
| `--no-images` | 이미지 노트는 건너뛰기 (영상만) |
| `--desc` | 제목·본문을 `.txt`로 함께 저장 |
| `--overwrite` | 같은 파일이 있어도 새로 받기 (기본은 건너뜀) |
| `--workers N` | 동시 다운로드 개수 (기본 3) |
| `--delay S` | 요청 간 간격(초, 기본 0.8) |

## 3. 저장 결과

```
001_一碗小面面 饭盒优等生 분격 설계.mp4     ← 번호_작성자_제목
002_작성자 제목_01.jpg                      ← 이미지 노트는 _01, _02 …
002_작성자 제목.txt                         ← --desc 를 켰을 때만
```
- 번호는 붙여넣은 순서라서 원래 목록과 대조하기 쉽습니다.
- 다운로드 중에는 `.part` 임시 파일로 받고, 완전히 받은 뒤에만 정식 이름으로 바뀝니다.
  → 중간에 끊긴 반쪽짜리 파일이 남지 않습니다.
- 이미 같은 이름이 있으면 기본적으로 건너뜁니다 (목록을 다시 돌려도 안전).

## 4. 쿠키가 필요한 경우

샤오홍슈는 로그인하지 않은 요청에 노트 내용을 잘 내주지 않습니다. **링크가 전부 똑같이 실패하면
링크가 만료된 게 아니라 쿠키가 없어서일 가능성이 큽니다.**

실패한 요청의 서버 응답 원본은 저장 폴더 아래 `_debug\<노트ID>.html` 로 남습니다. 원인을 직접
확인하거나 문의할 때 이 파일을 보면 됩니다.

1. 크롬에서 `xiaohongshu.com` 에 로그인
2. `F12` → **Network** 탭 → 페이지 새로고침 → 아무 요청이나 클릭
3. **Request Headers** 의 `Cookie:` 값 전체를 복사
4. GUI의 `쿠키(선택)` 칸에 붙여넣고 **설정 저장** (또는 CLI `--cookie "…"`)

저장된 설정은 `~/.xhs_dl/config.json` 에 들어갑니다. **쿠키는 계정 접근 권한이 있는 값이니 다른 사람과 공유하지 마세요.**

## 5. 자주 겪는 문제

| 증상 | 원인/해결 |
| --- | --- |
| `샤오홍슈 링크를 찾지 못했습니다` | 링크가 잘려 붙여넣어졌을 수 있습니다. `?xsec_token=…` 까지 전부 포함해야 합니다. |
| `페이지에 노트 데이터가 없습니다` | 로그인 벽에 막힌 것입니다(링크 만료 아님). 아래 4번의 쿠키를 넣으세요. |
| `노트 데이터가 비어 있습니다` | `xsec_token` 만료 또는 삭제·비공개 노트입니다. 앱에서 다시 공유해 새 링크를 받으세요. |
| `HTTP 461` / 캡차 | 요청이 너무 잦습니다. `--workers 1 --delay 3` 으로 낮추고 잠시 뒤 다시 시도하세요. |
| 이미지 노트만 있고 영상이 없음 | 해당 노트가 원래 사진 게시물입니다. `이미지 노트도 받기`를 켜세요. |
| GUI가 안 열림 | tkinter 미설치. 리눅스는 `sudo apt install python3-tk`, 아니면 명령줄로 사용하세요. |

## 6. 구조

```
extension/          크롬 확장 (권장 경로)
├── manifest.json
├── inject.js      페이지가 받는 노트 응답을 가로챕니다
├── content.js     노트 페이지의 저장 버튼
├── background.js  실제 파일 저장
├── app.js         링크를 하나씩 열고 주소를 뽑아 내려받습니다
├── extract.js     응답 → 영상·이미지 주소
├── links.js       붙여넣은 텍스트 → 링크 목록
└── naming.js      파일 이름 규칙

xhs_dl/             데스크톱 프로그램
├── links.py    붙여넣은 텍스트 → 링크 목록 (중복 제거, 단축 링크 인식)
├── http.py     urllib 기반 HTTP 클라이언트 (재시도·쿠키·부분 파일 처리)
├── extract.py  노트 페이지 → 제목/작성자/영상·이미지 주소
├── core.py     다운로드 실행, 파일명 정리, 동시 처리
├── cli.py      명령줄 인터페이스
├── gui.py      붙여넣기 GUI (tkinter)
└── config.py   저장 폴더·쿠키 등 사용자 설정
```

테스트:

```bash
python -m unittest discover -s tests -v   # 데스크톱 프로그램
node --test tests/extension.test.js       # 크롬 확장
```

## 7. 사용 시 주의

개인적으로 저장·감상하는 용도로 만들었습니다. 내려받은 영상과 이미지의 저작권은 원작자에게 있으니
재업로드·상업적 이용 전에는 반드시 원작자의 허락을 받으세요. 짧은 간격으로 대량 요청하면 계정이
제한될 수 있으므로 기본 설정(동시 3개, 0.8초 간격)을 크게 올리지 않는 편이 좋습니다.
