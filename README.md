# 샤오홍슈(小红书) 일괄 다운로더

공유 텍스트를 **그대로 한꺼번에 붙여넣으면** 영상(과 이미지)을 순서대로 내려받습니다.
파이썬 표준 라이브러리만 사용하므로 **따로 설치할 패키지가 없습니다.**

```
87 [饭盒优等生，분격 설계… - 一碗小面面| rednote …] jfHaah6nCCkXNqn https://www.xiaohongshu.com/discovery/item/69c2…?xsec_token=…
88 [다른 영상] http://xhslink.com/a/…
89 [또 다른 영상] https://www.xiaohongshu.com/explore/…
```
위처럼 번호·제목·토큰이 섞여 있어도 URL만 알아서 골라내고, 같은 노트가 여러 번 있으면 한 번만 받습니다.

## ⭐ 파이썬 설치 없이 쓰기 (윈도우 · 가장 쉬운 방법)

GitHub가 대신 빌드해 둔 **완성된 실행 파일 하나**만 받으면 됩니다. 설치 과정도 없습니다.

1. 아래 주소로 들어갑니다
   → https://github.com/nailblue1229-alt/-/releases/tag/app-latest
2. **`XHS-Downloader.exe`** 를 클릭해 내려받습니다
3. 받은 파일을 **더블클릭** → 창이 뜨면 링크를 붙여넣고 **다운로드 시작**

처음 실행할 때 파란 경고창이 뜹니다. 서명을 하지 않은 개인 빌드라서 나오는 정상적인 안내입니다.

> `Windows에서 PC를 보호했습니다` → **추가 정보** 클릭 → **실행** 버튼

바탕화면에 두고 쓰시면 됩니다. 매번 `.exe` 더블클릭 → 붙여넣기 → 시작, 이 세 동작이 전부입니다.

> 코드를 고쳐 올릴 때마다 **Actions** 탭에서 새 exe가 자동으로 만들어지고,
> `app-latest` 릴리스가 최신 파일로 교체됩니다.

### 직접 빌드하고 싶다면

```bash
pip install pyinstaller
python build_app.py     # dist/XHS-Downloader.exe 가 생깁니다
```

맥에서 실행하면 `dist/XHS-Downloader.app` 번들이 만들어집니다.

## 파이썬으로 실행하기 (개발자용)

### 준비

- 파이썬 3.9 이상 (윈도우/맥은 https://python.org 설치본에 GUI용 tkinter가 포함되어 있습니다)
- 리눅스에서 GUI를 쓰려면: `sudo apt install python3-tk`

### 실행 방법

### GUI (권장)

| 운영체제 | 방법 |
| --- | --- |
| 윈도우 | `run_gui.bat` 더블클릭 |
| 맥 | `run_gui.command` 더블클릭 (첫 실행 시 우클릭 → 열기) |
| 공통 | `python -m xhs_dl --gui` |

1. 큰 입력창에 공유 텍스트를 **Ctrl+V로 통째로 붙여넣기**
2. 저장 폴더 확인
3. **다운로드 시작** 클릭 — 아래 로그에 진행 상황이 한 줄씩 표시됩니다

### 명령줄

```bash
# 파일에 모아둔 링크 처리
python -m xhs_dl -i links.txt -o ~/Downloads/xhs

# 링크를 인자로 바로 전달
python -m xhs_dl "87 [제목] https://www.xiaohongshu.com/discovery/item/…"

# 파이프로 붙여넣기 (Ctrl+D 로 입력 종료)
python -m xhs_dl < links.txt

# 실제로 받지 않고 인식된 링크만 확인
python -m xhs_dl -i links.txt --list
```

주요 옵션

| 옵션 | 설명 |
| --- | --- |
| `-o, --out DIR` | 저장 폴더 |
| `--cookie` / `--cookie-file` | 로그인 쿠키 (아래 참고) |
| `--no-images` | 이미지 노트는 건너뛰기 (영상만) |
| `--desc` | 제목·본문을 `.txt`로 함께 저장 |
| `--overwrite` | 같은 파일이 있어도 새로 받기 (기본은 건너뜀) |
| `--workers N` | 동시 다운로드 개수 (기본 3) |
| `--delay S` | 요청 간 간격(초, 기본 0.8) |

## 3. 저장 결과

```
001_一碗小面面 饭盒优等生 분격 설계.mp4     ← 번호_작성자_제목
002_작성자 제목_01.jpg                      ← 이미지 노트는 _01, _02 …
002_작성자 제목.txt                         ← --desc 를 켰을 때만
```
- 번호는 붙여넣은 순서라서 원래 목록과 대조하기 쉽습니다.
- 다운로드 중에는 `.part` 임시 파일로 받고, 완전히 받은 뒤에만 정식 이름으로 바뀝니다.
  → 중간에 끊긴 반쪽짜리 파일이 남지 않습니다.
- 이미 같은 이름이 있으면 기본적으로 건너뜁니다 (목록을 다시 돌려도 안전).

## 4. 쿠키가 필요한 경우

대부분의 공개 노트는 쿠키 없이 받아집니다. 다만 `로그인이 필요하거나 인증(캡차)이 걸린 노트입니다`
라는 메시지가 나오면 로그인 쿠키를 넣어야 합니다.

1. 크롬에서 `xiaohongshu.com` 에 로그인
2. `F12` → **Network** 탭 → 페이지 새로고침 → 아무 요청이나 클릭
3. **Request Headers** 의 `Cookie:` 값 전체를 복사
4. GUI의 `쿠키(선택)` 칸에 붙여넣고 **설정 저장** (또는 CLI `--cookie "…"`)

저장된 설정은 `~/.xhs_dl/config.json` 에 들어갑니다. **쿠키는 계정 접근 권한이 있는 값이니 다른 사람과 공유하지 마세요.**

## 5. 자주 겪는 문제

| 증상 | 원인/해결 |
| --- | --- |
| `샤오홍슈 링크를 찾지 못했습니다` | 링크가 잘려 붙여넣어졌을 수 있습니다. `?xsec_token=…` 까지 전부 포함해야 합니다. |
| `영상/이미지 주소를 찾지 못했습니다` | 공유 링크의 `xsec_token` 은 시간이 지나면 만료됩니다. 앱에서 다시 공유해 새 링크를 받으세요. |
| `HTTP 461` / 캡차 | 요청이 너무 잦습니다. `--workers 1 --delay 3` 으로 낮추고 잠시 뒤 다시 시도하세요. |
| 이미지 노트만 있고 영상이 없음 | 해당 노트가 원래 사진 게시물입니다. `이미지 노트도 받기`를 켜세요. |
| GUI가 안 열림 | tkinter 미설치. 리눅스는 `sudo apt install python3-tk`, 아니면 명령줄로 사용하세요. |

## 6. 구조

```
xhs_dl/
├── links.py    붙여넣은 텍스트 → 링크 목록 (중복 제거, 단축 링크 인식)
├── http.py     urllib 기반 HTTP 클라이언트 (재시도·쿠키·부분 파일 처리)
├── extract.py  노트 페이지 → 제목/작성자/영상·이미지 주소
├── core.py     다운로드 실행, 파일명 정리, 동시 처리
├── cli.py      명령줄 인터페이스
├── gui.py      붙여넣기 GUI (tkinter)
└── config.py   저장 폴더·쿠키 등 사용자 설정
```

테스트:

```bash
python -m unittest discover -s tests -v
```

재업로드·상업적 이용 전에는 반드시 원작자의 허락을 받으세요. 짧은 간격으로 대량 요청하면 계정이
제한될 수 있으므로 기본 설정(동시 3개, 0.8초 간격)을 크게 올리지 않는 편이 좋습니다.
