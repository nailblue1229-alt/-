## 스킬 적용 결과

야담 스킬(v5)의 **산출물 구성과 검증 절차는 그대로 따르고**, 장르 규칙은 이 채널에 맞게 바꿨습니다.
바꾼 항목과 이유를 남깁니다.

| 스킬 항목 | 야담 기준 | 이 채널 적용 |
|---|---|---|
| 글자수 기준 | 공백 제외, python3 측정, ±3% | **그대로** |
| 전체 분량 | 26,500자 (60~90분) | **8,093자** — 참고 대본 3편 평균(5,521 / 8,463 / 10,294)에서 산출 |
| 장 구성 | 8장 (결핍·악행·사건·떡밥·반전·위기·정산·여운) | **8부** (도입·흑자·객단가·지갑·수출·경계·하루·마무리). 서사 곡선 대신 논증 순서 |
| 반전 지점 | 진행률 47% | **4부 끝(약 54%)** — "면세점에서 골목으로" 지점이 이 편의 반전 |
| 문체 | 구연 설화체 (~했지요 / ~하더랍니다) | **구어 해설체** (~습니다 / ~예요 / ~거든요). 참고 대본 3편의 실제 어미를 따름 |
| 줄바꿈 | 문단 안 줄바꿈 없음, 문단 사이 한 칸 | **그대로** |
| Show Don't Tell | 감정을 행동으로 | **숫자를 체감으로**. 모든 큰 수치 뒤에 환산 문장 의무 |
| 문단 의무 요소 | 행동·속말·감정 동작 | **비유 또는 환산 1회** — 가게 손님, 옆 동네 사과값, 저수지와 밭고랑 |
| 썸네일 화풍 | 한국 사극 웹툰체 | **실사 다큐 사진체** (02번 파일에 고정 프롬프트) |
| 썸네일=제목=오프닝 정렬 | 필수 | **그대로** — 셋 다 '장사'라는 한 장면으로 묶음 |
| 결말 | 따뜻한 결말 95% | **그대로** — 자부심으로 닫되 경계 4가지를 먼저 통과 |
| 제목 5안 / 더보기란 / 고정댓글 | 각 규격 | **그대로** (분량 기준 포함) |
